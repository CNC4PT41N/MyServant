# MyServant

面板样式由 `panel.json` 读取，当前为圣巢静夜主题：黑底、宋体文字菜单和细线纹饰。面板基准280×420像素，最大350×525像素，切换活动、修行、收藏页保持大小与位置不变，长内容在内部滚动。编辑／替换方式见 `PANEL.md`，此前浅色样式保留为 `panel-default.json`。

学习和工作内容现在从 `activities.json` 读取，当前启用空洞骑士主题。编辑／切换方式见 `ACTIVITIES.md`；原生活模拟版本保留为 `activities-default.json`。

Windows 桌面挂机养成原型，默认角色为火柴人。需要 Python（包含 tkinter）及 Pillow；当前机器已安装。图片角色使用 Windows 逐像素 Alpha 合成，避免透明边缘混入窗口底色。

角色显示会检查原生窗口的可见状态与透明合成模式；在用户选择显示时，意外隐藏或合成状态丢失会自动恢复，静止姿态也每秒补绘一次。临时窗口错误会重试，不会停掉动画更新或卸载角色。用户主动隐藏时保持隐藏。异常记录保存在 `Saved/diagnostics/runtime.log`，文件大小有限制。

启动时共用图片的路径与文件大小只检查一次，先读取首张待机图片，其余动画在首次使用时读取并检查尺寸。`python profile_startup.py` 可使用临时存档测量暖启动耗时；它不修改实际存档。

双击 `启动MyServant.bat`，或运行 `python main.py`。

- 点击火柴人打开面板，拖动移动，右键可退出或切换置顶。
- 拖动时使用悬空拖拽姿态，活动进度照常推进；暂停贴边切换、观察和反馈，取消正在进行的读屏并丢弃旧结果。松手后按新位置吸附并切换贴边姿态。图片角色可在 states 中提供 drag 帧，缺少时使用待机帧并摆动。
- 拖到屏幕可用区域边缘会轻微吸附。所有活动支持贴边姿态：放松与自由活动在左右侧靠边蹲下、上侧悬挂、下侧坐着；上班、学习、吃饭保留各自道具，睡觉切换为靠边蜷睡或横躺。拖离边缘恢复普通动作，不改变属性和收益。
- 系统托盘显示 MyServant 火柴人图标，左键恢复角色，右键可隐藏／显示角色、打开活动菜单或退出。隐藏仅影响显示，活动和自动存档继续。
- 每个 Windows 桌面会话只运行一个角色；再次启动会显示已有角色，不创建第二个进程实例。退出或异常终止后系统自动释放实例标记。
- 位置、贴边、隐藏、置顶状态自动保存；重启恢复。屏幕改变时位置自动限制在最近屏幕的可用区域内。
- 角色右键或托盘右键可切换“鼠标穿透”，状态自动保存，活动继续。托盘左键显示角色时同时关闭穿透；托盘的活动菜单和退出始终可用。
- 状态通过轻量动作反馈：疲劳减慢动作，休息或自由活动时偶尔点头、摸肚子或舒展肩臂。正常伸展间歇发生，不触发提示或额外奖励。图片角色通过轻微倾斜表达同类状态。
- 当前主题活动名称显示为“探险、修行、睡觉、吃饭、放松、自由活动”。存档中的工作、学习等名称保持兼容；旧“自主管理”自动迁移为“自由活动”。
- 工作、学习和休闲可安排 4、8、10 小时。睡眠 8 小时，进食 15 分钟。
- 属性不足会自动安排进食或睡眠。活动期间自动处理过度饥饿、疲劳。
- 工作赚取资金，学习积累所选方向的技能经验。总经验每100提升一级，职业和设备决定工作收入。
- 活动结束后进入自主管理，离线按真实时间推进。
- 点击角色在旁边展开无标题栏的浮动菜单，显示简短状态与活动按钮。默认不展开；鼠标移出或安排活动后收起。采用固定大小，适应屏幕可用区域；滚轮滚动内容，Tab与上下键选择，Enter执行，Esc返回。
- 存档位于程序目录的 `save.json`，首次运行自动生成。后台每5秒检查写入，更改计划、位置和开关后立即写入；没有状态变化时最多30秒写入一次，无需手动保存，正常关机后重启会补算离线进度。
- 写入使用临时文件、刷新磁盘及原子替换，降低中断造成文件损坏的风险。突然断电时仍可能丢失最后一次写入，但会从最近的存档时间补算进度。
- 旧版 `%LOCALAPPDATA%\MyServant\save.json` 在新文件不存在时自动读取并迁移，旧文件保留。

## 编辑和替换存档

先右键角色选择“退出”，然后用文本编辑器编辑 `save.json`，或将其他存档复制到此处覆盖，再启动游戏。运行期间编辑会被后台写入覆盖。

| 字段 | 含义 |
| --- | --- |
| hunger / energy / stress | 饥饿、活力、压力，0～100 |
| money / xp | 资金、技能经验，非负数字 |
| activity | 工作、学习、睡眠、进食、休闲或自由活动 |
| remaining | 当前活动剩余秒数 |
| queue | 后续计划，如 `[["学习", 10]]`，时长单位为小时 |
| updated | 上次推进时间，Unix 时间戳；加载后从该时间补算 |
| logs | 活动记录文字列表，界面不展示 |
| skills | office、tech、design 三个方向的非负经验 |
| study / plan_study | 下次学习方向／已安排计划的学习方向 |
| job / plan_job | 下次工作职业／已安排计划的职业 |
| owned | 已购设备编号列表：books、computer、bed、headphones |
| appearance | palette 配色、accessory 饰品；默认均为 null |
| desktop | x、y 桌面坐标；edge 贴边方向；hidden 隐藏；topmost 置顶；click_through 鼠标穿透 |
| plan_course / plan_work | 当前安排的课程阶段（路线与0～3阶段）／工作内容 |
| job_hours | 每个职业累计有效工作小时；100小时达到15%收入加成上限 |
| session / last_result | 当前活动成果统计／最近一次活动结果，无需领取 |
| works | 自动积累的成果名称与数量，无需领取或维护 |
| screen_feedback | 默认开启；下一次观察时间、当日次数与上一句反馈 |

文件需符合 JSON 格式；无效文件会提示错误，原文件不会被覆盖。

## 修行与收藏

修行页有骨钉、外壳、法术三个方向。骨钉可选择旋风劈砍、冲刺劈砍、强力劈砍；法术可选择复仇之魂、荒芜俯冲、嚎叫幽灵；外壳为落点练习、闪避练习、锤炼外壳。选择项目和时长后点“开始修行”。选择写入存档；正在进行的修行保持开始时的项目和方向，下一次安排才应用新选择。现有骨钉、外壳、灵魂动画编号继续使用。

活动页的“探险”打开目的地列表，经验门槛沿用原配置，选择目的地后点“开始探险”。低属性时的自动进食与补觉、离线推进、活动成果保持原有规则。

收藏页替代原商店。折叠地图60、旅人羽笔80、旧铃铛120、褪色披风160吉欧，每项只购买一次。“已收藏”筛选已拥有的藏品；藏品只作收藏，不增加属性或改变动画。旧版购买的设备、配色、饰品及其效果仍保存在原存档中。

新增存档字段：`training_choice` 保存三个方向各自的修行选择，`plan_training` 保存当前计划选定的项目，`keepsakes` 保存藏品编号。原有角色、活动和资金存档继续兼容。

## 角色文件

角色设置位于程序目录的 `character.json`，默认是火柴人，游戏内无角色选择页。右键角色“改名”可修改名称，名称显示在活动菜单中。修改角色文件会自动刷新；不影响养成存档。

默认配置：

```json
{
  "name": "MyServant",
  "renderer": "stickman",
  "color": "#e7edf3",
  "fps": 6,
  "states": {}
}
```

`name` 为1～20个字符；`color` 为默认火柴人颜色。已使用商店配色时，以商店配色为准，恢复原始配色后使用文件中的颜色。

若要替换为图片，将 renderer 改为 images，在 states 中指定程序目录内的图片路径，例如 `"idle": ["avatar.png"]`。支持透明 PNG 与单帧 GIF；多个文件按 fps 循环。活动名为 idle、work、study、sleep、eat、relax，仅 idle 必需，其余缺省使用 idle。图片建议200×200，底部对齐；超过200像素按整数比例缩小，最大1024×1024。fps 为1～20，每个活动最多60帧。

可以直接编辑或替换整个 character.json，不使用角色包。格式错误时保留最后成功读取的形象，首次读取失败则显示火柴人，原文件不会被覆盖。图片角色不叠加内置帽子、眼镜和配色。更新图片文件后重新启动，或同时修改 character.json 触发重载。

图片角色可指定活动与边缘组合的动画，如 work_left、study_top、sleep_bottom；也可指定通用 edge_left、edge_right、edge_top、edge_bottom。优先使用活动对应的贴边动画，其次通用贴边动画，没有提供则使用普通活动图片。角色旁不显示活动名称条。

## 低频屏幕反馈

默认开启，托盘菜单“屏幕反馈”可切换。每3～4小时观察一次，按中国时区每天最多4条。睡觉、隐藏或无合适内容时跳过；重启不补发错过的反馈。识别期间不会阻塞桌宠，气泡约6秒消失，无声音、不抢焦点、不要求回应、不产生奖励。

仅采样当前前台窗口的可见区域，通过窗口标题和本地 Windows OCR 粗略判断代码、文档、设计、游戏、视频、美食或旅行内容；没有云端请求。不是通用图片视觉模型，无文字的画面可能无法识别。截图只作临时OCR输入，处理完成删除，不进入存档；OCR不可用时使用窗口标题，类别不明确就跳过。对白为固定短句，不复述屏幕文字。

小骑士使用imagegen生成的4种观察姿态。反馈素材可用 feedback_look、feedback_notes、feedback_bowl、feedback_sit；贴边专用版本可添加 _left、_right、_top、_bottom。处于边缘时没有专用反馈素材，则保留原活动的贴边姿态，只轻微摆动，绝不使用普通反馈图替换悬挂、靠墙或底边姿态。
